# 青铃 v1.0.0

面向 Xiaomi HyperOS 3.0.10.0.VMICNXM 的音乐闹钟。

- 三种唤醒方式：纯音乐、纯振动、音乐 + 振动。
- 媒体通道播放，跟随系统耳机／蓝牙输出；耳机断开后转振动。
- 本地音乐导入、网易云公开歌单选曲缓存与离线循环播放。
- 一次性／按星期重复，5 分钟稍后提醒，锁屏响铃页与通知操作。
- 桌面小组件显示下一次闹铃和已开启状态，点击快速进入。
- 银白与青绿的原创 Q 版矢量角色、内置原创晨间铃声。
