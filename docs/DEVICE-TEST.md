# HyperOS 真机验收清单

设备目标：Xiaomi HyperOS 3.0.10.0.VMICNXM。以下项目需要安装最终签名 APK 后在真机上执行；Android 模拟器无法代替厂商后台管理与耳机硬件测试。

v1.1.0 已确认：用户使用 Baseus Bowie H1i 蓝牙耳机时，内置铃声和导入音乐均已可听见。以下新增项目建议优先复测：

- [ ] 同一首本地音乐分别用扬声器／蓝牙耳机试听；导入音乐显示 PCM 进度和非零峰值，实际输出与耳机一致。
- [ ] 从“去网易云”打开歌单，选择歌曲后分享给青铃；确认页显示这首歌。受限曲目标红且无法勾选。
- [ ] 三个底部模块分别进入正确页面；编辑返回“保存并返回”生效；“不保存”不改变已保存闹钟。
- [ ] 从编辑页跳转系统设置或网易云，再返回时草稿保留。
- [ ] 新版桌面闹钟表包含开启与关闭的全部闹钟，顶部下一次时间正确；闹钟多时列表可上下滚动。
- [ ] 已添加后应用按钮显示“已添加”；移除后可重新添加。从系统小部件列表尝试添加第二个时应被拒绝。
- [ ] 撤销精确闹钟、通知或全屏提醒后，系统设置对应项变红；开启后返回自动刷新。
- [ ] HyperOS 自启动、省电策略和后台弹窗需手动检查，手动确认不等同于系统自动检测。

- [ ] 首次安装允许通知、精确闹钟、全屏提醒，开启后台自启动与无限制省电。
- [ ] 创建两分钟后的闹钟：纯音乐、纯振动、音乐 + 振动分别验证。
- [ ] 有线耳机／USB-C 耳机、蓝牙 A2DP 各自试听并锁屏测试，确认媒体不从手机扬声器泄漏。
- [ ] 响铃中断开耳机，确认停止音乐并改为振动；无耳机时确认跟随系统扬声器输出。
- [ ] 媒体音量为 0、勿扰、通话、已有音乐播放时分别记录系统行为。
- [ ] 导入 MP3／FLAC，本地原文件移动后和飞行模式下仍可响铃；不支持格式给出错误。
- [ ] 读取公开网易云歌单，选择可播放曲目缓存；断网后响铃、循环、停止正常。
- [ ] 对不可播放／VIP／无效歌单显示失败结果，不覆盖原音乐来源。
- [ ] 桌面小组件显示下一次时间、模式、开启数量；添加、修改、删除、响铃后更新；点击进入。
- [ ] 响铃页／通知停止有效，稍后 5 分钟有效；编辑／关闭闹钟取消稍后提醒。
- [ ] 重启后在不首次解锁的情况下测试内置与已缓存铃声，并测试更改时区后的调度。
- [ ] 锁屏至少 30 分钟、应用退到后台、长时间待机后测试；不要用「强行停止」模拟普通后台。
- [ ] 撤销权限后应用显示缺失状态；恢复权限和重新打开应用后恢复计划。
- [ ] 同签名覆盖安装新版，已有闹钟保留；卸载前注意音乐缓存会被清除。

如果锁屏不弹出但通知出现，优先检查全屏提醒和 HyperOS 后台弹窗权限。如果完全不响，检查精确闹钟、自启动和省电限制。手机关机和强行停止不属于可保证的运行状态。
