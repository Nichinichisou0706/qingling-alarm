# 青铃 v1.1.0

已修复导入音乐在蓝牙耳机中无声的问题，并按反馈重构界面和桌面闹钟表。

- 导入音乐先解码为 PCM 立体声，再通过 AudioTrack 播放，避开压缩音频卸载与空间音频处理；显式优先已连接的媒体耳机。
- 用户已在 Xiaomi 真机 + Baseus Bowie H1i 上确认内置铃声与导入音乐均可听到；界面新增实际路由、解码进度与峰值显示。
- 三个独立模块：设定闹钟、我的闹钟、系统设置。编辑返回可保存、放弃或继续编辑；跳转网易云／设置前保留草稿。
- 网易云入口直接打开网易云选歌；选定歌曲后通过“分享 → 更多 → 青铃”返回。青铃确认页提前检查可导入状态，VIP／付费／无公开音频曲目标红且不可勾选，也支持粘贴链接。
- 桌面组件改为固定 4×4 的完整闹钟表，顶部显示下次闹钟，列表可滚动并包含关闭状态。已添加时按钮显示已添加并禁用；配置入口拒绝重复实例。
- 权限模块将可检测的缺失权限标红，提供电池优化白名单等入口；HyperOS 无公开检测接口的项目明确要求手动确认。
- 界面角色与头像图标采用用户指定的 Whom001x/- 仓库素材，保留来源说明。

验证：16 项 JVM 测试、29 项 Android 15 模拟器运行检查通过；真机蓝牙导入音乐经用户确认有声。

安装 `Qingling-1.1.0.apk` 可覆盖升级，保留已有数据。AAB 为分发包，source.zip 为源码，SHA256SUMS.txt 用于校验附件。

若已有 v1.0 旧桌面组件，请先移除旧组件，再添加新版闹钟表；移除组件不会删除闹钟。

网易云没有向本应用提供可回传选曲结果的原生选择器 API，因此使用用户分享返回；可导入标签显示在青铃确认页，不能修改网易云原生界面。不绕过 VIP、版权或登录限制。

系统权限与电池白名单能降低后台受限概率，不能保证系统永不杀进程；关机、强行停止及厂商限制仍需注意。完整长期待机验收见 docs/DEVICE-TEST.md。
